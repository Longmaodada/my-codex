# 隐私与安全边界

My Codex 是本地优先的个人桌面分析工具。此文档定义实现和验收都必须遵守的边界；界面文案不能替代代码层约束。

## 资产与威胁模型

需要保护的资产包括 Codex 登录凭据、账户/组织标识、Prompt 和回复、项目代码、完整本地路径、原始会话记录以及聚合使用数据。

主要风险：

- 应用或日志意外复制 Access Token。
- 宽泛解析会话文件后把正文写入 SQLite。
- 崩溃日志、调试日志或遥测泄露私有路径和文本。
- Mock 与真实数据混合，导致误判或截图泄露。
- 任意前端输入触发非预期文件读取。
- 本地数据库被同机其他用户或恶意软件读取。

My Codex 无法防御已经取得当前用户权限的恶意软件，但应尽量减少自身持有的敏感数据与存活时间。

## 网络边界

允许的网络行为：

- Codex app-server 代表当前用户与 OpenAI 服务通信；认证和 Token 刷新由 Codex 管理。
- 用户主动打开的外部帮助/项目链接。
- 未来若加入更新检查，必须单独披露目标域名、发送字段和关闭开关。

禁止的网络行为：

- 向 My Codex 作者、分析平台或其他第三方上传 Access Token、账户 ID、Prompt、聊天记录、项目代码、项目路径或统计数据库。
- 未经明确说明的遥测、广告标识、指纹、崩溃上传和远程配置。
- 把本地 session/event 文件交给远程模型分析。

当前设计不包含遥测或云同步。网络不可用时，官方额度显示 stale/unavailable，本地历史仍可查询。

## 认证边界

- 用户在 Codex 中完成登录；My Codex 不提供 OpenAI 密码输入框。
- 默认使用本机 app-server 的账户 RPC，不读取或保存 `auth.json`。
- 不在 SQLite、设置文件、前端状态、剪贴板或日志中持久化 Access/Refresh Token。
- 进程输出中疑似 Bearer/JWT/Cookie/账户 ID 的值必须脱敏。
- 若未来引入直接认证文件兼容层，必须是显式选择、单独威胁评审和独立版本变更，不能静默启用。

## 本地文件边界

Session Analytics 只允许访问已知 Codex 数据位置和用户明确选择的附加位置。解析采用字段白名单，禁止根据日志内容中的任意路径继续递归读取文件。

允许持久化：

- 聚合 Token、请求、会话、模型、缓存和日期桶。
- 本地项目显示名、路径或路径的稳定本地标识。
- 结构化 Skill 名称、调用计数、置信度。
- 设置、窗口位置、解析游标、schema 版本和最后成功时间。

禁止持久化：

- Prompt、回复、reasoning、shell/patch 正文。
- 项目文件内容、附件和原始会话行。
- Access Token、Refresh Token、Cookie、原始账户 ID。
- 未脱敏的错误响应或认证路径。

项目路径是敏感本地数据：可为用户自己的排行显示保存在本地，但不进入网络请求、遥测、公开诊断包或普通日志。导出功能若未来加入，必须让用户预览并默认隐藏路径。

## SQLite 与保留

- 数据库保存在应用专属本地数据目录，不放入仓库、云同步目录或临时公开目录。
- SQL 使用参数绑定，数据库 migration 固定版本，不执行来自 session 文本的 SQL。
- 默认只保留产品所需的日/项目/Skill 聚合；原始事件不入库。
- “清除本地统计”必须删除统计表、解析游标和缓存快照，但保留或删除设置由 UI 明确区分。
- 清除动作应在事务中执行，完成后刷新 UI；未实现安全擦除承诺，因为 SQLite/SSD 不能可靠保证物理不可恢复。

## 日志与诊断

默认日志仅包含：模块、时间、状态码类别、耗时和匿名事件计数。禁止写入 Token、Prompt、原始响应、原始 session 行、完整账户 ID 和完整私有路径。

诊断导出（若加入）应：

1. 先在本地生成脱敏预览。
2. 显示具体包含的文件和字段。
3. 由用户主动保存，不自动上传。
4. 对路径保留 basename 或哈希，不保留用户目录。

## 前端与 IPC

- Tauri 命令参数使用明确类型和白名单枚举，拒绝任意文件路径/命令执行。
- IPC 只传递可序列化 DTO，不传 Token、原始事件或文件句柄。
- CSP 默认只允许自身资源和 Tauri IPC；不引入远程脚本、远程字体或第三方像素。
- URL 打开功能只接受固定帮助链接或经过协议/域名校验的链接。
- UI 中的项目名和路径按纯文本渲染，不能解释为 HTML。

## 截图与 Mock

仓库内 `references/` 图片由用户提供，仅作视觉参考。发布截图应使用 Mock 数据并检查窗口中没有邮箱、账户 ID、私有路径、真实项目名或通知内容。Mock 状态必须在 UI 中可见，避免截图被误认为官方额度证明。

## 用户控制

用户应能：

- 关闭本地 Session Analytics，而仍查看可用的官方额度。
- 清除本地统计、缓存快照和项目路径。
- 关闭开机启动、通知、全局快捷键和自动刷新。
- 查看每类数据的来源、最后更新时间和不可用原因。

## 明确不承诺

- 本项目不是 OpenAI 官方安全产品或账单系统。
- 本地聚合不等于 OpenAI 账单，且可能因日志缺失而不完整。
- “Local First”不代表操作系统账户失陷后仍能保密。
- 当前源代码尚未完成经过签名安装器和干净机器的安全验收；状态以 [acceptance.md](acceptance.md) 为准。
